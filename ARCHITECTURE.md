# Architektura

ARC-MUSIC jest samodzielnym prywatnym repozytorium zespołowym. Nie zależy od innych prywatnych repozytoriów ani ich sekretów.

- `research/`: model, protokoły i instrumenty.
- `manuscripts/`: kanoniczne źródła LaTeX.
- `portfolio/`: rejestry prac.
- `docs/`: zwięzła dokumentacja wewnętrzna.
- `pages/`: wyłącznie materiały przeznaczone na stronę publiczną; `site/` to wynik kompilacji MkDocs.
- OneDrive VIZJA: dane empiryczne, zgody i materiały identyfikowalne.
- Discord: komunikacja.

Kod analizy i dane syntetyczne mogą trafić do Git po kontroli prywatności. Nie tworzymy dodatkowej bazy ani aplikacji bez uzasadnienia metodologicznego.
