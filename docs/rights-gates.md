No license inferred from a local PDF or platform subscription. Before approved pilot, log instrument/version, owner/license evidence, exact permitted uses (translation, administration, storage, publication), responsible reviewer, date, restriction and approved storage location in restricted institutional records. Public repository contains only non-sensitive status, approved aggregate outputs and synthetic fixtures; no protected item text, actual participant records, private bank credentials, identifiers or consent/contact files. No claim that all items are original if derived from a third-party measure. Use VIZJA institutional OneDrive only after controller/storage authorization. Retention and deletion must follow the approved policy, not an implementation default. Ethics determination, recruitment text, distress protocol and consent must be approved before collecting data. Preregister frozen hypotheses, estimands, measures, recruitment and analysis before confirmation. Missing external approvals are blocking conditions, not completed tasks.
