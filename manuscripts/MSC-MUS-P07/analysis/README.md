PROSPECTIVE. Research owner: Mateusz Pomianek; authorship determined by actual contribution. No participant data. The unit is a prescheduled window, not a creation session. Retain all scheduled windows. The initial estimate uses complete observed switchers, not causal inference. No comparison of creation vs non-creation across different people as the primary model.

Run python -m unittest -v in this directory after installing requirements.txt. Run python inference.py responses.csv --schedule schedule.csv --withdrawals withdrawals.csv on a frozen authorized export, never in CI with participant data. The code implements H1–H3, outcome-specific complete switcher sets, Holm correction with a fixed two-hypothesis secondary family, common complete-subset models and a narrower timing sensitivity. Field capture, full missingness and power calibration, and pilot measurement checks remain open. No field application, ethics approval or enrollment.

Power design: vary participant propensities and serial dependence, outcome-dependent exposure, floor/ceiling, informative missingness. Calculate probability of usable within-person contrasts, power under the observed-scale target and coverage. Do not interpret the count of windows as independent observations. Distinguish exposure missingness from outcome missingness.

Bibliography: targeted DOI-backed metadata search on 2026-11-26; sources on listening are indirect, Huang et al. directly concern creation but not affect outcomes. Full-text audit and current journal conditions pending. The 21-day schedule and single-item ratings are provisional.

Narrow timing comparison uses baseline 0–5, exposure/first outcome 60–65 and late outcome 180–185 minutes. H2 does not require the H1 response; H3 requires initial desired arousal and first-hour actual arousal, not valence60. An unavailable secondary model does not reduce the planned Holm family. Common-subset comparisons are descriptive. No raw identifiers are included in output; report counts, not identities.

Run python simulation.py --smoke --reps 20 --reference-n 1000 for smoke testing or python simulation.py --reps 200 --reference-n 10000 for the 44-cell synthetic screen. See simulation-plan.md. The simulator calls the same array estimator as the production H1 model. No sample target is locked; output is not empirical data.

H1 missingness sensitivity now separately reports invalid/missing exposure and outcome among valid baselines. Sequential ridge-logistic weights for exposure availability and outcome availability are capped at 10/20; these are point estimates only. Deterministic outcome shifts (five additive by three exposure-dependent shifts) retain known exposure. Stochastic exposure scenarios vary log-odds by -1/0/+1 among valid outcomes, with fixed seed and 100 draws; no unknown exposure is classified as non-creation. Scenario quantiles are not uncertainty intervals. Neither analysis recovers missing baselines or jointly missing exposure/outcome. Bootstrap, joint missingness calibration and H2/H3 sensitivities remain pending. Initial CI calibration results are archived separately.

Rare-creation stress calibration: see stress-plan.md. The new 24-cell grid uses 1000 replicates per cell and separately models ineligibility, timing failures and informative monotone withdrawal. It records unconditional rejection and switcher-count quantiles, not just conditional power. Results are archived in stress-results-n160-v0.5.0.json and stress-results-n320-v0.5.0.json.

Generate a frozen 21-day schedule using python schedule.py enrollment.csv schedule.csv --seed <approved-seed>. Use an enrollment-defined fixed daily time band and IANA timezone; the prompt must leave 210 minutes for the maximum baseline delay (15) plus final follow-up (195). Ambiguous or nonexistent local times are rejected or skipped. The schedule must be frozen before observation, stored privately and never regenerated to fit data. The analysis CLI requires the authoritative schedule and left-joins response records, including people with no response at all. It rejects unscheduled, duplicate or contradictory records. Response-record presence is not valid baseline completion. All planned windows remain in the planned denominator; active prompt denominators exclude windows at or after the cessation cutoff. No notifications, live data collection, or ethics approval are implied.

The withdrawal log is required in the CLI; a header-only file explicitly represents no recorded cessation events. Reject responses at or after cessation and records for cancelled windows. Distinguish an in-progress possible window at withdrawal from subsequent cancelled prompts. Retention and deletion requests must be handled before export under approved institutional procedures. See pilot-protocol.md for provisional feasibility review triggers and freeze criteria. No live collection.
