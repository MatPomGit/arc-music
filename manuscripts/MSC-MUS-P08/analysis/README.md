PROSPECTIVE. Research owner: Mateusz Pomianek. H1 marginal decision-authority contrast on ownership; H2 same contrast on agency; H3 authority-by-execution interaction on ownership. Effect coding -0.5/+0.5, baseline covariates only, HC3 and fixed two-test Holm family. Preserve randomised denominators; never score absent or unheard output as zero. Run python -m unittest -v in this directory; python inference.py assigned.csv on approved locked exports only. The initial code estimates complete-outcome models. Full missingness calibration, secure allocation service integration, stimulus development, independent psychometric assessment, final power calibration, ethics and independent review remain pending. Initial bibliography checked at metadata level on 26 November 2026; full-text and rights audit pending. No field application or participant data.

Initial 36-cell synthetic screen: python simulation.py --reps 500 --reference-n 40000; see simulation-plan.md. The H1 and H2 main contrasts and the H3 interaction use the same production estimator. H2/H3 rejection includes Holm correction. No power results are claimed before CI execution.

Missingness: each composite receives cell-based worst/best bounded marginal contrast ranges, ridge logistic outcome-availability weighting (caps 10/20), and 27 deterministic bounded mean-shift scenarios across common, authority and interaction shifts. Bounds concern hypothetical defined scores for everyone; for unheard output the construct is not actually observed or necessarily defined. They do not identify a treatment effect on ownership of an unheard work. IPW and scenario outputs are point diagnostics, not calibrated confidence intervals or multiple imputation. Missing scores remain missing in the main analysis. Bootstrap and missingness simulation are pending.

Allocation: allocation.py implements a local SQLite prototype with variable blocks 4/8/12 per training stratum, OS-backed randomness, atomic allocation, unique participant IDs and idempotent retries. Seeded RNG is synthetic-test-only. This is not a field service. Authentication, private storage permissions, eligibility/consent checks, independent allocation oversight and secure deployment are not implemented. Never expose pending slots or commit allocation databases.
