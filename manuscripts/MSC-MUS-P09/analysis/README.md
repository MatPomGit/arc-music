## Defined-outcome inference candidate

The target is the marginal difference in mean original-event outcomes between assigned groups, not a contrast among respondents. A defined but unobserved score (including an incomplete item composite, wrong event or invalid visit) is missing, not structural undefinedness. The candidate uses arm-specific Hájek IPW under conditional MAR, positivity and a sufficiently accurate response model, with the same baseline predictors and penalty as the existing sensitivity estimator. It refits response probabilities in a whole-participant bootstrap stratified by assignment and training; a centered absolute-error interval and plus-one two-sided bootstrap p-value are evaluated. Undefined or unresolved targets, prespecified overlap warnings (minimum probability below .05 or effective sample size below half the observed sample), numerical failures and more than 5% failed bootstrap refits withhold candidate inference. The candidate uses a fixed Holm family H2/H3, retaining both slots if a test is unavailable. The legacy complete-outcome HC3 output and historical percentile sensitivity results are unchanged. The candidate is not an approved replacement and never emits a confirmatory p-value. MNAR shifts remain sensitivity analyses, not identified effects.

Run `python assignment_candidate.py assigned.csv --ledger restricted.sqlite --reps 999` only with authorized, reconciled records; use `python calibrate_assignment_candidate.py --smoke --n 600 --reps 2 --draws 199` for a synthetic execution check. The full development grid covers complete data, MCAR, linear and nonlinear MAR, low overlap and MNAR, global null, all-positive effects and partial null; report candidate availability, conditional/operational error and coverage, bias, RMSE, MCSE and secondary true-null FWER. Prespecify scientific acceptance criteria with the owner before high-precision calibration: proposed screening criteria are ≥95% availability under the intended MCAR/MAR profiles, absolute bias ≤0.05 scale points, pointwise coverage ≥.93 and null rejection/FWER ≤.06 allowing for Monte Carlo uncertainty. These are development targets, not validated thresholds; evaluate power at the owner-approved smallest meaningful effect. Use independent seeds and sufficiently many outer replications (e.g. at least 2,000 per intended cell) and 999 bootstrap draws for final calibration; no recruitment or confirmatory decision follows from a smoke test. MNAR and misspecified response models may fail these criteria, which requires sensitivity reporting and potentially redesign.

## Resumable candidate calibration

`candidate_shards.py` evaluates the actual candidate, not historical percentile-IPW or HC3. The 40-cell grid crosses N440/600, complete/MCAR/MAR/MNAR and null/joint/partial alternatives plus nonlinear/low-overlap MAR stress. For each cell, fixed seed and global replicate index determine independent draws; combine disjoint contiguous index ranges with strict metadata/denominator checks. For example `python candidate_shards.py shard 0 0 20 --draws 999 > shard-0.json`, then `python candidate_shards.py aggregate . --expected 20`. Use separate folders per cell and source revision; retain exact source SHA. The initial CI screen is small, not a final calibration. Report individual Holm-adjusted rejection as well as true-null FWER (undefined when no secondary null is true), availability, operational/conditional coverage and bias. The point estimator skips unused shift calculations only; tests compare the old and optimized IPW exactly. Existing shift sensitivity is unchanged. No confirmation or sample-size selection.

Independent 20×999 per-cell screen: [candidate-precision-evidence.md](candidate-precision-evidence.md), 80 datasets and 239,760 successful refits. MNAR true-null secondary FWER 4/20; partial-null H3 Holm rejection 6/20. Still NO-GO; repeated same-seed CI does not increase independent outer N.

Separate `augmented_candidate.py` implements arm-specific AIPW using the same response model and overlap gate, OLS baseline conditional means and the unnormalized residual augmentation. It refits both models in the same stratified participant bootstrap. Complete data reduce to arm means; rank failure is unavailable. Out-of-range outcome predictions/means are flagged rather than silently clipped. Under conditional MAR and positivity, a correctly specified response or conditional mean model can support consistency; finite-sample behavior and MNAR remain unresolved. `compare_candidates.py` pairs both methods on identical generated datasets and seeds, compares availability, bias, coverage, error and squared-error differences. Neither is adopted; no method selection on empirical significance.
