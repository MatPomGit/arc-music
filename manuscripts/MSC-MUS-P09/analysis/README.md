# P09 prospective protocol v0.6.2

Research owner: Mateusz Pomianek. Two-arm experiment: private autobiographical text plus selected AI-generated instrumental setting versus the same text plus selected nonfigurative visual setting. Both use a fixed selection-and-reflection task. H1 day-7 understanding, H2 immediate understanding, H3 immediate distance. No actual lyrics, personal prompts or narratives are collected. Proposed measures are not validated; event-specific self-understanding is not global narrative identity.

Run python -m unittest -v, python power.py, and python inference.py assigned.csv --ledger restricted.sqlite on approved locked records. Timing and same-event checks are endpoint-specific. H1/H2/H3 use HC3 regression; fixed Holm family H2/H3. Unadjusted hypothetical bounds and 25 bounded shift scenarios are point diagnostics, not calibrated intervals. Run python missingness.py assigned.csv --ledger restricted.sqlite --reps 999 for marginal Hajek IPW and 25 bounded arm-specific shift scenarios with refitted stratified participant bootstrap. The pointwise percentile intervals are uncalibrated; report missing fits and weight diagnostics. The original adjusted shifts are a distinct point diagnostic. The required target_status1/2 fields distinguish defined (including nonresponse or invalid assessment of an originally defined event), genuinely undefined and explicitly unresolved targets; the latter two block full-cohort numerical sensitivity analysis. Valid observed scores cannot coexist with undefined/unresolved status. A negative connection is not an undefined target. All randomised rows must be retained; allocation.py implements an offline transactional ledger, cohort reconciliation and cessation marker; the production export adapter, consent authentication and approved withdrawal retention policy remain pending. See online-protocol.md. stimulus_bank.py validates declarations and hashes, not actual rights or media decoding; task.py implements the shared offline time/selection contract. Synthetic fixtures are not stimuli.

Planning calculations: 90% power, alpha .05, d=.30 gives 470 complete, 588 randomised assuming 20% loss. At d=.35, 346 and 434. No final sample target. The implemented A01.4 calibration crosses two sample sizes, four bounded-score profiles, four missingness mechanisms and null/alternative effects (64 cells). Run OPENBLAS_NUM_THREADS=1 python calibration.py --reps 200 > calibration-grid.json for the initial screen; use --reps 2000 for greater Monte Carlo precision. The production HC3 estimator is called directly on synthetic prepared endpoints; the existing inference tests separately exercise raw-record preparation. The report distinguishes fitted-only coverage/rejection from operational rejection across all attempts. H2/H3 share T1 missingness; Holm false-rejection is reported for the true null subset. The original grid is retained. Run OPENBLAS_NUM_THREADS=1 python calibration_extended.py --reps 30 --draws 99 --raw-reps 200 > calibration-extended.json. It screens 12 bootstrap cells (360 independent data sets, 35,640 requested bootstrap draws) and four raw-record cells (800 data sets) with item omissions, invalid timing and incorrect or unknown event flags. The screen reports conditional versus operational coverage, failures, bias/MCSE and zero exclusion. MNAR coverage against complete-data truth is a stress metric, not a confidence guarantee; the range of shift points is not a CI. The low outer/inner replication counts are not definitive calibration of 999-draw intervals. Block randomisation and higher precision remain pending. Run python missingness.py --demo --reps 199 for three synthetic H1 examples, not coverage evidence. Pilot 30–50, no pilot effect-based sample selection. See bibliography-audit.md for six added sources and explicit claim-transfer boundaries, and measurement-validation.md for the proposed expert review, cognitive interviews, process diagnostics and pilot decision flags. Full-text audit, comparator rights, approval and empirical validation remain pending. No recruitment or production system.

See calibration-audit.md for inspected exact-HEAD historical artifact results and the remaining decision gates. Undefined/unresolved targets suppress confirmatory p-values and Holm entries rather than treating descriptive tests as confirmatory.

Historical grids remain available. No high-precision result claimed before artifacts are inspected.
