# Calibration and recruitment screening protocol

Baseline evidence: extended-monte-carlo-audit.md (cee6e03, all 12 scenarios). New diagnostics do not overwrite or recertify that evidence.

H6: hold the profiled ML point estimate fixed and replace its conditional model-based standard error with a participant-cluster score sandwich, CR1 correction, t(G-p) reference (G observed participant clusters, p fixed effects). This is a candidate asymptotic robust covariance, not CR2 or a demonstrated finite-sample cure; it cannot correct MNAR selection or misspecified conditional mean. Compare paired model-based and robust rejection/coverage on independent seed 91307+N. Report valid fraction and bias; require a subsequent precision study if calibration is inconclusive.

H10: avoid poorly identified random-slope covariance as a working model by estimating the same first-to-last arm difference via marginal quadratic arm-by-time regression, using cluster sandwich intervals. Compare available case and estimated retention IPW, which assumes observed-history MAR, positivity and a correct retention model; current analytic sandwich treats fitted weights as fixed. For final inference evaluate participant bootstrap refitting propensity and uncertainty, not just fixed-weight intervals. No claim that independence working covariance makes repeated observations independent.

Screen N=160,400,800,1200, K=8, null and illustrative effect -.35, complete/MAR/MNAR. Report bias, coverage, rejection, Wilson MC intervals, valid fraction and last-session observation fraction. Each cell has 500 paired draws, not sufficient for MCSE .005 near .05 or precision certification. Candidate design must attain acceptable null rejection and coverage under justified MAR, at least 80% power, with uncertainty reported, and a feasible sample size; reject any recommendation based solely on nominal MNAR power. Assess MNAR via fixed-delta sensitivity, not a purported universal correction. If no feasible N qualifies, retain H10 as exploratory or defer to a dedicated study. Do not select effect size from simulated estimates. No human data or recruitment authorisation.

Workflow publishes exact-SHA output. H6 uses N=80 solely to compare intervals, not a new recruitment recommendation. New H10 estimator and grid do not repeat earlier mixed likelihood diagnostics. All decisions are provisional pending actual outputs and independent scientific review.
