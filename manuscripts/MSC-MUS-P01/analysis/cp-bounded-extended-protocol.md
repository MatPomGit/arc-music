# Extended bounded CP calibration

Version 1.0.0. Synthetic development only. No human observations, approved recruitment target or confirmatory analysis decision.

The original 360-cell bounded grid remains unchanged. This extension crosses N=1600, 2000, 2400, 3000, 4000, 5000; eleven simple-effect pairs (symmetric .15, .30, .45, .60; asymmetric .15/.45 and reverse; global null, partial null and reversed components in both orientations); three mean levels; two beta-binomial concentrations; six observation mechanisms. Total 2376 scenarios. Effects are raw points on the 0–10 scale, not standardised d. The differential MNAR profiles vary both retention intercept and outcome slope across matched and mismatched cells. They preserve the full-population outcome distribution. Neither ordinary complete-case inference nor standardisation identifies MNAR effects.

Compare available-case and known-population-weight standardisation with five fixed pattern-mixture missing-minus-observed mean shifts. Shifts are specified by assigned cell and clipped to the feasible mean range. Pointwise delta-method variance includes retention uncertainty; coverage is conditional on valid replicates, rejection counts all attempted replicates. The sensitivity estimator is not claimed to have valid inference under arbitrary MNAR. Independent simulations and stakeholder justification of plausible shifts are required. No selection of shifts by favourable results.

Run from analysis with Python and the existing requirements. Smoke: python cp_bounded_extended.py --smoke --reps 200 --workers 4 --output ../results/cp-extended-smoke.json. Full: python cp_bounded_extended.py --reps 20000 --workers 8 --seed 20261129 --output ../results/cp-extended-full.json. Progress to stderr; partial JSON checkpoint every ten scenarios, complete flag only at successful termination. Existing output files are not overwritten. Checkpoints are not automatically resumable. Seed indexed by scenario ensures reproducibility across worker counts. Full grid is intended for local computation; CI runs a small synthetic screen.
