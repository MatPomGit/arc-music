# MSC-MUS-P04 analysis
Status: PROSPECTIVE. The canonical protocol and hypotheses are in main.tex.
Install requirements in an isolated Python environment. Run python -m unittest -v, python power.py and python simulation.py --reps 250 --imputations 10 with OPENBLAS_NUM_THREADS=1.
The primary score is a composite, not conditional fit. Confirmed absence of a meaningful sketch is zero, unknown status or missing applicable fit is missing. Use design() with covariates ordered as baseline expression ease, clarity, distress, prior music-generation experience and scenario mode. The primary N-DDF moderator is standardised across all randomised participants before excluding outcomes. analyze() returns HC3 complete-outcome and MAR PMM pooled estimates, predicted availability, assignment contrasts and 27 missingness sensitivity scenarios. The confirmatory plan uses 50 imputations; the calibration run uses 10 for cost control. Arm-specific imputation uses observed outcome donors; it is not guaranteed consistent under all heteroskedastic or nonlinear mechanisms.
The simulation has 12 scenarios (480/1000 randomised, latent interaction 0/.40 raw points, complete/MAR/MNAR), with a 10% structural-zero process independent of assignment. It reports actual valid and failed counts, bias, MCSE, RMSE, coverage and rejection with Wilson Monte Carlo intervals. The true composite interaction is .90 times the latent fit interaction. Heteroskedastic binomial-mixture outcomes preserve the conditional mean. See calibration-evidence.md for verified synthetic output. The simulation is a limited calibration, not evidence that real data follow the assumed mechanisms; more extensive calibration, completion-dependent missingness, correlated covariates and alternative imputation models remain appropriate before preregistration.
The idealised power calculation predates the composite endpoint and is not final sample-size evidence; a meaningful raw-unit effect and feasibility target must be frozen before recruitment. Psychometric scoring, endpoint cognitive interviews and further model validation remain open. No participant records or proprietary questionnaire items belong in Git.

## Extended calibration
secondary.py implements both secondary analyses, arm-specific PMM, fixed two-test Holm family and sensitivity grids. calibration.py evaluates a nominal result versus the stricter all-grid directional evidence criterion. See calibration-evidence.md for exact-head prior results. Run python calibration.py --reps 120 --imputations 10. The extended calibration was executed on head 41e2df3, see calibration-evidence.md. Further calibration with 50 imputations remains open.

exploratory.py fits alternative PAQ moderators in a common complete-baseline subset and a three-knot restricted cubic spline, using the same nonlinear basis in imputation and analysis. Both analyses are exploratory. Use authorised facet sums; no item text is included. The full primary sensitivity grid now emits a directional robustness label. These new routines require exact-head CI.

## Completion-dependent calibration (50 imputations)
See completion-calibration.md. New simulation uses paired synthetic data, compares the baseline primary estimator and status-informed sensitivity estimator, and distinguishes confirmed structural zeros from unknown completion. The workflow executes six scenarios with 120 replications and 50 imputations per method. Prior 10-imputation results are not independent evidence for the new DGP. No empirical participant data are used.
