# MSC-MUS-P04 analysis
Status: PROSPECTIVE. The canonical protocol and hypotheses are in main.tex.
Instrument decision: PAQ-S-PL (six items, one total 6–42). Full PAQ facet scoring and facet-specific H1/H2 are superseded before recruitment. paq_scoring.py rejects 24-item inputs, missing totals for randomised cases, and invalid ranges; no item wording is included. All randomised cases require the complete total. H1 uses the standardised observed total; H2 and H3 use the same randomised population with fixed Holm adjustment. exploratory.py retains spline moderation only. The outcome design, HC3, PMM, Rubin pooling, 27 sensitivity scenarios and completion-aware supplementary estimator are unchanged. Historical simulations with generic standardised moderators remain technical evidence, not PAQ-S-specific power. completion_calibration.py now generates six correlated ordinal items and uses their observed sum; it does not claim to reproduce the Polish validation distribution or reliability. The latent generator is hypothetical; its exact conditional outcome truth is defined on the observed score. See completion-calibration.md and calibration-evidence.md. Run python -m unittest -v, python power.py and the dedicated simulation workflows with pinned dependencies and OPENBLAS_NUM_THREADS=1. The minimum meaningful effect and feasible cap must be determined anew. Instrument administration terms, sample-specific omega, pilot, ethics and independent review remain open. No participant records or proprietary item text belong in Git.

reliability.py implements categorical omega via ordinal moment modelling and participant bootstrap; measurement_calibration.py separates observed-score and oracle latent-score estimands under three hypothetical item-noise levels. See measurement-calibration.md for assumptions and failure rules. No participant reliability or new simulation result is claimed before execution.

Verified numerical outputs from both targeted calibration workflows are documented in paqs-calibration-evidence.md. See readiness-audit.md for unresolved scientific and implementation gates. Green and Yang (2009) provides the nonlinear summed-score reliability rationale; our moment estimator is not identical to their SEM fitting procedure.


## Empirical cohort gate (candidate schema v1)
Use `python empirical.py COHORT.csv --ledger ASSIGNMENT.csv --data-kind empirical --out REPORT.json` only with authorized institutional data after ethics, instrument and analysis freeze. The independent ledger contains exactly `study_token,assignment`; include every authorized randomized record, even if outcomes are missing. P04 token is `p04-` plus a random lowercase canonical UUIDv4, not shared with P03/P06. Reconcile all tokens and assigned arms, validate complete PAQ-S (six integer 1–7 items or authoritative 6–42 integer total, sum agreement when both supplied), baseline ranges and derived composite. Required fields in the data dictionary; optional six item columns are all-or-none. Scenario codes `personal_mild` and `fictional`; fit reasons explicitly distinguish confirmed absent (`undefined`), unknown or unavailable rating (`unavailable`/`withdrawn`), and observed rating (blank). Retain only legally authorized records; if withdrawal prevents cohort reconciliation, block full-cohort inference. Aggregate component counts and conditional mean are descriptive, not causal effects of production. H1–H3 and spline sensitivity use the same validated assigned cohort; low-level continuous helpers remain synthetic interfaces. No empirical confirmation authorized by this gate.
