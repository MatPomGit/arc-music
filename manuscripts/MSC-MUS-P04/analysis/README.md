# MSC-MUS-P04 design sensitivity

Status: PROSPECTIVE. The canonical protocol and hypotheses are in main.tex.
Run from this directory: python -m unittest -v and python power.py.
The calculation is an idealised normal approximation for a treatment-by-standardised-trait interaction; it is not an empirical finding, exact finite-sample power or a model of missing data.

Before registration, implement and validate the HC3 regression, bounded-outcome simulations, MAR imputation, arm/moderator-dependent missingness and outcome-undefined sensitivity; freeze the raw-unit smallest effect, pilot endpoint wording, record instrument permissions and obtain approval. No participant records or proprietary questionnaire items belong in Git. Synthetic fixtures must be clearly labelled.
