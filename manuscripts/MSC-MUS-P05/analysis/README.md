# Analysis plan and reproducibility

Prospective only. The canonical statistical protocol is in sections/analysis.tex. The Python module provides only preliminary correlation planning and defensive domain-scoring functions. It is not an ordinal EFA/CFA implementation, does not establish factor recovery, and cannot validate the instrument.

Before recruitment implement and independently verify polychoric/ordinal parallel analysis, ordinal CFA with robust DWLS, ordinal reliability and bootstrap inference, missing-data procedures, and sample-size simulation. A Python implementation must be benchmarked against a trusted independent ordinal estimator; normal-theory CFA on raw scores is not a substitute. Freeze estimator version, seeds, category thresholds, factor correlation matrices, minimum group sizes and acceptance rules. At least 1000 replicates per core scenario and 2000 near decision boundaries; report Monte Carlo uncertainty. Grid: N 250/400/500/650/800; loadings .40/.60/.75; factor correlations .20/.50/.80; balanced vs skewed categories; 0/10/20% missing (MCAR/MAR plus MNAR sensitivity); include cross-loadings/local dependence and rare-category stress. Record convergence, improper estimates, factor recovery, bias, coverage and external validity power. Simulation is not participant data.

Run from repository root: python3 -m unittest discover -s manuscripts/MSC-MUS-P05/analysis -p 'test_*.py'; python3 validate.py.

## Ordinal development implementation v0.2.0

ordinal_efa.py now implements deterministic two-step polychoric estimation, permutation parallel analysis (500 by default), MINRES with promax oblique rotation and explicit sparse-category/non-PD/boundary/improper-fit failures. It does not silently smooth matrices or collapse categories. Complete cases are required for EFA development; missing data are not scored as zero. recovery.py generates ordinal synthetic scenarios and evaluates known-factor assignment and loading bias; optional parallel analysis estimates factor count. The CI smoke test uses 36 simulated nine-item datasets and is not the final seven-domain calibration. Run the full-pool scenario with --full-pool; use --pa-reps 500 for the protocol (computationally demanding). No robust ordinal CFA, uncertainty calibration, MAR/MNAR implementation or empirical validation is claimed. Independent estimator comparison is still required.

## Ordinal CFA development v0.3.0

ordinal_cfa.py fits a frozen simple structure to two-step polychoric correlations, using observed conditional pair information as diagonal working weights. Standardized latent responses, positive anchor loadings, a normalized Cholesky factor-correlation matrix and explicit improper-fit checks are implemented. The weights do not account for uncertainty in empirical thresholds; this is not WLSMV, does not implement robust chi-square, and must not be used for final inference. A participant bootstrap recomputes all moments and weights; it reports failures and withholds intervals below 95% proper fits. ordinal_reliability.py distinguishes latent-response omega from model-implied observed ordinal sum-score reliability under conditional independence. cfa_calibration.py runs three 35-item scenarios (24 replications in CI), reporting proper fits, errors and domain reliability. This is a smoke calibration, not evidence for the final sample-size requirement. The protocol still requires independent estimator comparison, robust fit/inference, coverage, invariance, MAR/MNAR and validity contrasts. CI 45892064058 passed on f2be72f; artifacts 15152351096 and 15151917081 were confirmed present, but not visually or numerically inspected here.

## Robust ordinal DWLS development v0.4.0

robust_cfa.py derives empirical marginal-threshold influence functions and propagates them through the pairwise polychoric estimating equations. The full empirical cross-pair covariance is retained for sandwich inference. Inverse diagonal moment variances determine DWLS weights; direct loading and factor-correlation Jacobians determine parameter influence functions. The residual test uses a two-moment scaled chi-square approximation with possibly fractional degrees of freedom. This is not certified WLSMV: robust CFI/TLI/RMSEA, independent estimator comparison and large-replication calibration remain open. No inference is issued for improper or ill-conditioned fits. Wald intervals are not clipped to parameter boundaries; their coverage requires calibration. The complete-record estimand remains selection-sensitive. robust_calibration.py adds 66 synthetic development replications across four scenarios, six of which use all 35 items, with explicit failure accounting and Wilson intervals for Monte Carlo proportions. The small replication counts cannot establish 95% coverage or type-I error control. The prior CI 45892825483 passed at 493f27f; it confirms execution, not numerical success of every simulated scenario. New results pending.
