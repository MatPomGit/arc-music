# Analysis plan and reproducibility

**Current method boundary (2026-11-28).** All new execution is Python-only. The one-factor, correlated-seven and higher-order development models use ordinal moment fitting and a moment-matched residual test, not WLSMV. Earlier external-reference computations and paired comparisons describe historical revisions, not a validated current estimator. Independent Python ordinal reference, robust fit/invariance equivalence, full calibration and scientific approval remain blocked. Archived evidence is retained; no results are transferred to the new estimator.

Prospective only. The canonical statistical protocol is in sections/analysis.tex. The Python module provides only preliminary correlation planning and defensive domain-scoring functions. It is not an ordinal EFA/CFA implementation, does not establish factor recovery, and cannot validate the instrument.

Before recruitment implement and independently verify polychoric/ordinal parallel analysis, ordinal CFA with robust DWLS, ordinal reliability and bootstrap inference, missing-data procedures, and sample-size simulation. A Python implementation must be benchmarked against a trusted independent ordinal estimator; normal-theory CFA on raw scores is not a substitute. Freeze estimator version, seeds, category thresholds, factor correlation matrices, minimum group sizes and acceptance rules. At least 1000 replicates per core scenario and 2000 near decision boundaries; report Monte Carlo uncertainty. Grid: N 250/400/500/650/800; loadings .40/.60/.75; factor correlations .20/.50/.80; balanced vs skewed categories; 0/10/20% missing (MCAR/MAR plus MNAR sensitivity); include cross-loadings/local dependence and rare-category stress. Record convergence, improper estimates, factor recovery, bias, coverage and external validity power. Simulation is not participant data.

Run from repository root: python3 -m unittest discover -s manuscripts/MSC-MUS-P05/analysis -p 'test_*.py'; python3 validate.py.

## Ordinal development implementation v0.2.0

ordinal_efa.py now implements deterministic two-step polychoric estimation, permutation parallel analysis (500 by default), MINRES with promax oblique rotation and explicit sparse-category/non-PD/boundary/improper-fit failures. It does not silently smooth matrices or collapse categories. Complete cases are required for EFA development; missing data are not scored as zero. recovery.py generates ordinal synthetic scenarios and evaluates known-factor assignment and loading bias; optional parallel analysis estimates factor count. The CI smoke test uses 36 simulated nine-item datasets and is not the final seven-domain calibration. Run the full-pool scenario with --full-pool; use --pa-reps 500 for the protocol (computationally demanding). No robust ordinal CFA, uncertainty calibration, MAR/MNAR implementation or empirical validation is claimed. Independent estimator comparison is still required.

## Ordinal CFA development v0.3.0

ordinal_cfa.py fits a frozen simple structure to two-step polychoric correlations, using observed conditional pair information as diagonal working weights. Standardized latent responses, positive anchor loadings, a normalized Cholesky factor-correlation matrix and explicit improper-fit checks are implemented. The weights do not account for uncertainty in empirical thresholds; this is not WLSMV, does not implement robust chi-square, and must not be used for final inference. A participant bootstrap recomputes all moments and weights; it reports failures and withholds intervals below 95% proper fits. ordinal_reliability.py distinguishes latent-response omega from model-implied observed ordinal sum-score reliability under conditional independence. cfa_calibration.py runs three 35-item scenarios (24 replications in CI), reporting proper fits, errors and domain reliability. This is a smoke calibration, not evidence for the final sample-size requirement. The protocol still requires independent estimator comparison, robust fit/inference, coverage, invariance, MAR/MNAR and validity contrasts. CI 45892064058 passed on f2be72f; artifacts 15152351096 and 15151917081 were confirmed present, but not visually or numerically inspected here.

## Robust ordinal DWLS development v0.4.0

robust_cfa.py derives empirical marginal-threshold influence functions and propagates them through the pairwise polychoric estimating equations. The full empirical cross-pair covariance is retained for sandwich inference. Inverse diagonal moment variances determine DWLS weights; direct loading and factor-correlation Jacobians determine parameter influence functions. The residual test uses a two-moment scaled chi-square approximation with possibly fractional degrees of freedom. This is not certified WLSMV: robust CFI/TLI/RMSEA, independent estimator comparison and large-replication calibration remain open. No inference is issued for improper or ill-conditioned fits. Wald intervals are not clipped to parameter boundaries; their coverage requires calibration. The complete-record estimand remains selection-sensitive. robust_calibration.py adds 66 synthetic development replications across four scenarios, six of which use all 35 items, with explicit failure accounting and Wilson intervals for Monte Carlo proportions. The small replication counts cannot establish 95% coverage or type-I error control. The prior CI 45892825483 passed at 493f27f; it confirms execution, not numerical success of every simulated scenario. New results pending.

## Selection sensitivity v0.5.0

The complete-record estimator can be biased under MAR or MNAR. missingness.py implements logistic complete-record IPW with always-observed auxiliaries; weighted ordinal thresholds and polychorics; discrete-stratum exponential-tilt pattern-mixture sensitivity (delta from -3 to 3); and participant bootstrap refitting of both propensity and measurement model. Report effective sample size, overlap, maximum weight, failed fits and withheld intervals. No trimming is automatic. This is a complete-record sensitivity analysis, not item-level multiple imputation or robust WLSMV. It assumes positivity and correct propensity specification under MAR; MNAR delta is unidentified. A tilt of +2 matches the synthetic MNAR mechanism on the log odds scale; it is not established for real participants. The oracle IPW is solely a simulation comparator. The CI smoke calibration covers 90 independent datasets and six methods per dataset. Calibration of interval coverage and broader patterns remain open. No empirical participant data are used.

## Ordinal group comparability diagnostics v0.6.0

invariance.py fits the same configural structure separately in independent groups and constructs cumulative Wald diagnostics using affine threshold links. Outer thresholds identify each item response location and scale relative to the reference; the two internal threshold locations test shape. With invariant thresholds and unstandardized loadings, linked loading ratios are constant within each domain (factor SD ratio). Equal intercepts additionally imply a constant linked shift divided by reference loading (factor mean shift). Group means/variances may differ under the null. The joint threshold/loading covariance uses empirical influence functions, including cross-moment dependence. The provisional minimum is 150 complete records per group with category support and positive loadings; it is not a calibrated sample-size recommendation. A rejected earlier gate blocks later interpretation. Nonrejection does not establish equivalence or justify mean comparisons. No latent mean is returned. These diagnostics are not nested multi-group WLSMV and require independent comparison and coverage/power calibration. CI smoke scenarios include 120 simulated two-group datasets (250 per group) with unequal factor means/variances under invariance and threshold, loading or intercept violations. No actual participants. The earlier CI 45893153993 passed; CI 45893355394 was still running when inspected.

## Ordinal multiple imputation v0.7.0

ordinal_imputation.py implements independent seeded FCS chains with Bayesian ordinal probit conditional models: first cut fixed at zero, unit residual variance, proper Gaussian priors and Gibbs updates for latent responses, regression parameters and remaining ordered cuts. Only observed target outcomes enter conditional model fitting, while other items use current imputed values. Missing responses are drawn in 0..4, and observed entries remain unchanged. The defaults are 50 chains and 100 sweeps, not a validated convergence guarantee. MNAR sensitivity shifts missing-item latent means in residual SD units. The same seeds permit controlled sensitivity comparisons; delta is unidentified. Pool parameters and covariance by Rubin's rules with large-complete-data-df t intervals; do not pool fit statistics. Any improper completed-data fit blocks pooling. Trace summaries are retained; formal chain diagnostics, compatibility, predictor specification, independent reference and coverage calibration remain open. CI adds 24 synthetic six-item development datasets, five imputations per sensitivity method; this is a small smoke study, not sample-size evidence. Previous CI 45893710926 passed all computational steps at inspection; PDF compilation was still running. No participant data.

## Fit and chain diagnostics v0.8.0

The fit module uses a common diagonal-weight correlation discrepancy for target and independence models, with free thresholds in both. It records ordinary DWLS discrepancy indices and explicitly nonstandard trace-corrected CFI-like, TLI-like and RMSEA-like diagnostics, subtracting expected quadratic discrepancies under the fitted model and independence baseline. These are not validated robust WLSMV indices or an RMSEA confidence interval. TLI-like may exceed one or fall below zero; undefined baseline comparisons return null. Paired synthetic calibration uses 90 data sets and 180 model fits. No universal fit cutoffs are applied. The ordinal imputation module now records retained per-item imputed-mean traces and rank-normalized/folded split R-hat and approximate bulk ESS screening. Minimum four chains and 20 retained draws; R-hat <=1.01 and ESS >=400 are provisional flags only. Constant or degenerate traces return unavailable. This is not a joint posterior convergence certificate, and a screen flag does not silently remove imputations. Final robust indices, calibrated sample size, independently benchmarked estimators, and substantive validity inference remain open. CI 45894003009 passed unit tests at inspection; later steps were pending.

## External validity and sample-size decision v0.9.0

validity.py implements the six H3--H5 slots, authorization-gated domain means, Spearman and partial rank correlations, paired correlation differences on identical complete triples, participant bootstrap intervals and centered two-sided bootstrap p-values, Holm correction retaining unavailable slots at p=1, and positive-direction support flags. Comparators must be independently authorized and frozen; no proprietary items copied. Complete-record associations are selection-sensitive; bootstrap p-values need calibration. validity_calibration.py simulates 300 independent 35-item datasets across five candidate sample sizes and two latent comparator association settings. CI uses 199 bootstrap draws rather than the protocol's 5000; it is a smoke screen, not final power evidence. sample_size_plan.md defines the full decision grid and blocks selection until core criteria are met. CI 45894003009 and 45894186937 were still running at inspection; both had passed unit tests. No empirical results.

## v0.10.0 reference checks

The independent conditional-normal quadrature test uses a distinct probability formulation and likelihood optimization for a synthetic pair. It is not a full independent CFA/WLSMV implementation or independent scientific review. The previous validity test failed because 99 bootstrap draws cannot produce a Holm-adjusted p <= .05 with six slots; the test now verifies this limitation and the 199-draw case. The primary 5000-resample protocol and alpha remain unchanged. See bibliography_audit.md for targeted source checking.

## Full-pool calibration infrastructure v0.11.0

calibration_grid.py --list enumerates 60 scenarios (40 complete-data core, five weak/high-correlation stress, 15 MCAR complete-case stress). Run a shard with --scenario 0 --offset 0 --count 10 --out shard-000.json. Aggregate disjoint same-scenario shards with --aggregate shard-000.json shard-010.json; duplicate replicate IDs and mixed seeds are rejected. ## Factor-count and correlation interval calibration v0.12.0

The factor-count driver selects the count by ordinal parallel analysis, extracts the selected model, and retains failed, wrong-count and improper solutions. Only proper correct-count solutions enter assignment/bias calculation. Joint recovery requires correct count, proper fit, assignment >=.90 and absolute mean primary loading bias <=.05 (development thresholds). Default 500 permutations. CI runs two six-item datasets at 500 permutations and two 35-item datasets at 20 permutations; neither establishes full-pool factor-count recovery. Interval comparison includes Wald, Fisher-delta, percentile and basic bootstrap; each participant bootstrap refits all moments and weights. Bootstrap intervals withheld below 95% proper fits. CI compares six synthetic datasets, 99 draws per dataset; full protocol 2000. No method is selected based on smoke tests. Results uploaded ahead of the long suite. Previous CI runs 45894529075 and 45894820297 passed unit tests and remained in progress at inspection.

## Item diagnostics and group power v0.13.0

Item diagnostics records category counts, missingness, corrected item-rest rank correlations, and residual polychoric dependence flags with optional proper frozen CFA parameters. Flags (.80 extreme endorsement, .10 missingness, .30 item-rest, .15 residual) are provisional review triggers, not automatic deletion criteria. Invariance power evaluates balanced and 70:30 allocations at total N=500/800, with all four prior DIF scenarios; reports conditional and unconditional rejection rates and Monte Carlo uncertainty.
